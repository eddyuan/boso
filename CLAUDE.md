# Tielo

Read [OVERVIEW.md](OVERVIEW.md) first — it describes the product, architecture, auth, onboarding,
the pet agent, API routes, data model and known gaps.

## Keep OVERVIEW.md current

Whenever a change adds, removes or changes app behaviour (features, screens, API routes, schema,
config/env vars, known gaps or decisions), update the relevant sections of `OVERVIEW.md` in the same
change, bump its "Last updated" date, and add a line to its Changelog. Tick off or remove items in
"Known gaps" when they're resolved.
